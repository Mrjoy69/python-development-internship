# Level 1: Python Fundamentals

This level contains beginner-friendly Python projects developed as part of my Python Development Internship at Codveda Technologies.

The assignments focus on building a strong foundation in Python programming, problem-solving, and user interaction.

## Tasks

### Task 1: Simple Calculator

**File:** `Task_1/calculator.py`

A command-line calculator that performs basic arithmetic operations.

**Concepts covered:**

* Variables and data types
* User input and output
* Arithmetic operators
* Conditional statements
* Error handling

### Task 2: Number Guessing Game

**File:** `Task_2/guessing_game.py`

A command-line game where the user attempts to guess a randomly generated number.

**Concepts covered:**

* Variables and data types
* User input and output
* Conditional statements
* Loops
* Python's `random` module

## Technologies Used

* Python 3
* Visual Studio Code

## Learning Objectives

* Understand Python fundamentals.
* Apply conditional statements and loops to solve problems.
* Build interactive command-line applications.
* Improve logical thinking and problem-solving skills.
