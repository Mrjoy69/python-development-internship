# Level 3 — Python Development Internship

This directory contains my Level 3 assignments for the Python Development Internship at Codveda.

The projects demonstrate my practical understanding of Python development, web application development, file handling, and data security.

## Tasks

### Task 1: Django Authentication Web Application

**Location:** `Task_1/`

A Django web application that implements user authentication.

Key concepts:

* Django project structure and configuration
* User registration and login
* Authentication and session management
* HTML templates and form handling
* URL routing and views

See the [Task 1 README](Task_1/README.md) for setup instructions and further details.

### Task 2: File Encryption and Decryption

**Location:** `Task_2/`

A Python command-line application that encrypts and decrypts files using Fernet symmetric encryption from the `cryptography` library.

Key concepts:

* File handling in Python
* Symmetric encryption and decryption
* Secure encryption key management
* Exception handling
* Interactive command-line menus

See the [Task 2 README](Task_2/README.md) for setup instructions and further details.
