# Level 2: Intermediate Python Projects

This level contains intermediate Python projects completed as part of my Python Development Internship at Codveda Technologies.

The assignments focus on working with external APIs, handling JSON data, managing application dependencies, and building practical command-line applications.

## Task 1: API Integration

**Location:** `Task_1/api_integration.py`

A Python application that demonstrates how to interact with an external API and process the returned data.

**Concepts covered:**

* Making HTTP requests
* Working with external APIs
* Processing JSON responses
* Handling errors and exceptions
* Managing Python dependencies with `requirements.txt`

### Requirements

The required Python packages are listed in `Task_1/requirements.txt`.

## Task 2: JSON-Based To-Do List

**Location:** `Task_2/todo_app.py`

A command-line task management application that uses a JSON file to store tasks.

**Data file:** `Task_2/tasks.json`

**Concepts covered:**

* Reading and writing JSON files
* File handling
* Lists and dictionaries
* Functions and modular programming
* Managing and updating task records

## Technologies Used

* Python 3
* JSON
* HTTP requests and APIs
* Git and GitHub

## Learning Objectives

* Integrate Python applications with external APIs.
* Process and manage JSON data.
* Persist application data using files.
* Handle errors and exceptions appropriately.
* Build practical command-line applications.
